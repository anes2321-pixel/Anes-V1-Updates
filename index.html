Häufige Fragen

Was brauche ich zum Spielen?

Minecraft 1.21.11, Fabric Loader, Fabric API und Java 21. Die Mod läuft client-seitig.

Wo bekomme ich neue Versionen?

Neue Versionen werden im GitHub-Repository unter „Releases“ bereitgestellt, sobald ein Release veröffentlicht wurde.

Ändern Cosmetics das Gameplay?

Die Cosmetics sind visuelle Anpassungen. HUD- und Komfortfunktionen ändern die Anzeige auf deinem Client.
