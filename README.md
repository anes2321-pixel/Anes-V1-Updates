# Anes V1 Website

Statische, eigenständige Website für Anes V1. Sie verwendet keine Build-Tools oder externen Bilddateien.

## GitHub Pages veröffentlichen

1. Lade den Inhalt dieses Ordners in das Repository `anes2321-pixel/Anes-V1` hoch.
2. Öffne im Repository **Settings → Pages**.
3. Wähle **Deploy from a branch**, Branch `main` und Ordner `/ (root)`.
4. Speichere die Einstellung. GitHub zeigt danach die veröffentlichte Seitenadresse im Pages-Bereich.

Die Download- und Update-Links führen zum Bereich **Releases**. Eine JAR erscheint dort erst, wenn sie separat als Release-Datei veröffentlicht wurde.
